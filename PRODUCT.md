# Doko

## Register

product

## Product purpose

Doko is a local-first reader and annotation tool for PDF, Markdown, and photo folders, built for Windows, macOS, and Linux. Preserve document contents, editing behavior, keyboard shortcuts, and local data.

## Visual direction

The user selected a premium, modern, restrained identity: the approved geometric mark, Mint accent, quiet surfaces, and existing Inter/system typography. Preserve the product layout. Prefer consistent controls, clear selection, visible keyboard focus, and soft hover feedback.

## Current explicit requirements

Use the shared 12px radius for UI control surfaces. Keep color samples circular inside comfortably sized buttons. Use Mint for accents, Ink for text on Mint, and a darker green for contrast in light themes. Existing annotation colors remain user document choices.
